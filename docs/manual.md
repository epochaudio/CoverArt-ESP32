# CoverArt ESP32 使用说明书

中文 · [English](manual.en.md)

适用固件：0.6.0

> 0.5.x 中 C3-LCDkit 和 BOX-Lite 的代码随板级接口重构做了调整，尚未在实机上验证；需要稳定使用这两款设备的用户可暂留在 0.4.1。

CoverArt ESP32 把一块 ESP32 小屏变成 Roon 的专辑封面显示器。设备本身就是一个 Roon 扩展：插电、连上 Wi-Fi，在 Roon 里启用一次，之后就自动跟随你选定的 Zone 显示当前播放的封面。不需要电脑、手机 App 或 Home Assistant 常驻运行。

---

## 1. 使用前提

- 局域网里有一台运行中的 Roon Core（Roon Server 或 Roon 桌面版均可）。
- 2.4 GHz Wi-Fi，与 Roon Core 在同一网段。设备不支持 5 GHz。
- 首次安装固件需要一台装有 Chrome 或 Edge 的电脑和一根 USB 数据线；预装好的成品可跳过安装。

## 2. 支持的设备与功能

| 功能 | ESP32-C3-LCDkit | ESP32-S3-BOX-Lite | 微雪 ESP32-S3-Touch-AMOLED-2.16 |
|---|---|---|---|
| 屏幕 | 1.28" 240×240 圆形 LCD | 2.4" 320×240 LCD | 2.16" 480×480 AMOLED |
| 封面显示 | ✓（铺满圆屏，四角被裁切） | ✓ | ✓ |
| 操作方式 | 旋钮 | —（仅显示） | 触摸 + 体感 |
| 设备上调音量 | ✓（旋钮） | — | —（在 Roon 或功放上调节） |
| 自动变暗 / 熄屏 | — | — | ✓ |
| 防烧屏 | — | — | ✓ |
| 电池 | — | — | ✓ |
| 恢复出厂 | 连续插拔电源 | 连续插拔电源 | 长按屏幕 10 秒（或连续插拔电源） |

## 3. 安装固件

已预装固件的设备跳过本节。

1. 用电脑版 Chrome 或 Edge 打开 <https://epochaudio.github.io/CoverArt-ESP32/>。
2. 选择开发板型号，用 USB 线连接设备，点击“安装”，在弹出的列表里选中设备所在的串口。
3. 提示是否擦除设备时选择擦除，等待写入完成（约 1 分钟）。

> 通过网页重新安装会清除设备上的全部设置（Wi-Fi、Roon 配对、Zone），安装后需重新完成第 4 节的设置。

## 4. 首次设置

### 4.1 连接 Wi-Fi

设备没有保存过 Wi-Fi 时，会自动进入配网模式：

1. 屏幕显示 **WI-FI SETUP**、一个二维码和网络名 **CoverArt-XXXXXX**（后六位因设备而异）。
2. 用手机相机扫描二维码，加入这个网络（无密码）。也可以在手机 Wi-Fi 列表里直接选择它。
3. 手机会自动弹出设置页面；如果没有弹出，用浏览器打开 `http://192.168.4.1`。
4. 在页面上选择家里的 Wi-Fi（也可以手动输入名称），输入密码，点“连接”。
5. 设备尝试连接约 20 秒：
   - 成功：屏幕显示 **WI-FI OK / Restarting**，设备重启，设置网络随之关闭，手机会回到原来的网络。
   - 失败：屏幕重新显示二维码。重新加入设置网络后，页面会提示“无法连接”，检查密码后重试。

页面只列出 2.4 GHz 网络。网络名称或密码里的中文都可以正常输入。

### 4.2 在 Roon 中启用

1. 打开 Roon → **设置 → 扩展**。
2. 找到本设备的扩展（发布者“门耳朵制作”），点击“启用”。AMOLED-2.16 显示为 **CoverArt Mini**，其他型号显示为 **CoverArt_ESP32_<型号>**。
3. 点击该扩展的“设置”，在 **Select playback zone** 中选择要跟随的 Zone，保存。AMOLED-2.16 在这里还有 **屏幕亮度 Brightness**（20%–100%，默认 100%），保存后立即生效。

完成后屏幕会立即显示该 Zone 当前播放的封面。每台设备在 Roon 里都是独立的扩展，可以同时使用多台设备，各自跟随不同的 Zone。

扩展列表中，设备下方会显示一行状态，例如：

> 已连接 Roon Core，显示 HQ · 电量 80%（充电中）

电量部分只在接有电池的设备上显示。

### 4.3 屏幕提示说明

| 屏幕显示 | 含义 | 你需要做什么 |
|---|---|---|
| WI-FI SETUP + 二维码 | 配网模式 | 按 4.1 设置 Wi-Fi |
| CONNECTING WI-FI | 正在连接已保存的 Wi-Fi | 等待；超过 3 分钟连不上会自动回到配网模式 |
| FINDING ROON CORE | 正在局域网中查找 Roon Core | 等待 |
| ROON CORE NOT FOUND / Retrying | 没有找到 Roon Core，会持续重试 | 确认 Roon Core 已开启、与设备在同一网络 |
| In Roon open Settings > Extensions, enable CoverArt Mini（其他型号为 CoverArt_ESP32） | 等待在 Roon 中启用 | 按 4.2 启用扩展 |
| In Roon extension settings, choose a zone | 已启用，尚未选择 Zone | 在扩展设置中选择 Zone |
| NOTHING PLAYING | 所选 Zone 当前没有播放 | 在 Roon 中开始播放 |

## 5. 日常使用

### 5.1 封面显示

- 切歌后约 1 秒内换成新封面。
- 暂停或停止时保留当前封面。
- 曲目没有封面时屏幕显示黑色。
- 断电或断网恢复后自动重新连接 Roon，无需重新启用。

### 5.2 触摸操作（AMOLED-2.16）

| 手势 | 功能 |
|---|---|
| 单击屏幕 | 播放 / 暂停 |
| 向左滑动 | 下一首 |
| 向右滑动 | 上一首 |
| 按住屏幕 10 秒 | 恢复出厂（需确认，见第 8 节） |

- 屏幕变暗或熄灭时，第一次触摸只会点亮屏幕，不会执行操作。
- 这款设备不在屏幕上调音量，请使用 Roon App 或功放调节。

### 5.3 旋钮操作（C3-LCDkit）

| 操作 | 功能 |
|---|---|
| 向右转 / 向左转 | 音量增大 / 减小，每格一步 |
| 单击 | 播放 / 暂停 |
| 双击 | 下一首 |
| 按住旋钮转动 | 只调音量，松开时不算单击 |

### 5.4 体感操作（AMOLED-2.16）

| 动作 | 功能 |
|---|---|
| 把设备屏幕朝下扣在桌上（约 1 秒） | 正在播放则暂停，同时熄屏 |
| 翻回屏幕朝上 | 点亮屏幕；满足条件时自动恢复播放（见下） |
| 拿起或挪动设备 | 屏幕变暗或熄灭时将其点亮 |

翻回后只有同时满足以下条件才会自动恢复播放，避免意外出声：

- 这次暂停是由“扣下”触发的；
- 距离扣下不超过 30 分钟；
- 期间没有在 Roon 中恢复播放或切换曲目。

手指按在屏幕上时，体感操作不生效。

### 5.5 音量安全（C3-LCDkit 旋钮）

- 每一格调整一步，步长由 Roon 中该输出决定；以 dB 计的输出一步就是 1 dB。
- 音量每秒最多升高 6 步（dB 输出即 6 dB），转得再快也不会超过；降低不受限制。
- 如果所选输出在 Roon 中是固定音量，旋钮调音量无效。

## 6. 屏幕与防烧屏（AMOLED-2.16）

AMOLED 屏长时间显示同一画面会留下残影，设备会自动保护：

| 状态 | 屏幕 |
|---|---|
| 正在播放 | 正常亮度：扩展设置中选择的亮度（默认 100%） |
| 停止或暂停 5 分钟 | 变暗（20% 亮度，不超过所选亮度） |
| 停止或暂停 15 分钟 | 熄灭 |
| 屏幕朝下 | 立即熄灭 |
| 与 Roon Core 断开 | 视为停止，按上面的时间变暗、熄灭 |

- 触摸屏幕、拿起设备、Roon 开始播放或切换曲目时，屏幕都会重新点亮。
- 播放期间每 3 分钟把封面整体移动 2 个像素，循环往复，肉眼几乎察觉不到，用于防止烧屏。

C3-LCDkit 和 BOX-Lite 使用 LCD，屏幕保持常亮。

## 7. 电池（AMOLED-2.16）

- 插着 USB 时自动给电池充电。
- 电量显示在 Roon 扩展状态行中，每变化 5% 更新一次，充电时注明“充电中”。
- 使用电池且电量不高于 20% 时：
  - 屏幕顶部中央出现红色电池图标；
  - 屏幕最高亮度限制为 50%。
- 新电池头几次充放电时，电量百分比可能不够准确，几个充放电周期后会稳定。

## 8. 恢复出厂设置

恢复出厂会清除：Wi-Fi 设置、Roon 配对、所选 Zone、记住的 Roon Core 地址。之后设备重新进入配网模式；在 Roon 中可能需要重新启用扩展。

**方法一：长按屏幕（AMOLED-2.16）**

1. 按住屏幕 10 秒，期间手指不要移动。
2. 屏幕显示 **FACTORY RESET?** 和 **OK** 按钮，松开手指。
3. 10 秒内点击 **OK** 确认。点击其他位置或超时则取消，回到封面。

**方法二：连续插拔电源（所有设备）**

1. 插上电源，5 秒内拔掉。
2. 再重复一次：插上，5 秒内拔掉。
3. 第三次插上电源时执行恢复出厂，屏幕显示 **FACTORY RESET / Settings erased**。

只有完全断电再上电才计数。接着电池的 AMOLED-2.16 拔掉 USB 并不会断电，请使用方法一。

## 9. 网络行为

- 设备通过局域网广播自动发现 Roon Core，并记住最近一次连接的地址。广播偶尔失败时，会用记住的地址直接连接。
- 已保存的 Wi-Fi 连续 3 分钟连不上（例如更换了路由器），设备自动进入配网模式。
- 在配网模式下，设备每 2 分钟尝试一次原来的 Wi-Fi；路由器只是临时断电的话，恢复后会自动连回。
- 运行中 Wi-Fi 断开超过 3 分钟，设备自动重启并按上述规则处理。

## 10. 常见问题

**Roon 扩展列表里找不到设备**
确认设备屏幕已越过 FINDING ROON CORE，并且与 Roon Core 在同一网段。部分路由器或 Mesh 网络会过滤组播，可尝试重启路由器，或让设备与 Roon Core 连接同一台路由器。

**屏幕一直显示 ROON CORE NOT FOUND**
检查 Roon Core 是否运行。同上，组播被屏蔽时，设备第一次无法发现 Core；成功连接过一次之后，设备会记住地址。

**重新安装固件后要再次在 Roon 中启用**
网页安装会清除设备上的配对信息，属正常现象，按 4.2 重新启用即可。

**旋钮调音量没有反应**
所选输出可能是固定音量，需在 Roon 的设备设置中改为可调音量。

**封面更新慢或偶尔不更新**
多为 2.4 GHz 信号弱。尝试把设备移近路由器；设备会在 10 秒内自动重连并重新获取封面。

**设置页面没有自动弹出**
在手机仍连接 CoverArt-XXXXXX 网络时，用浏览器打开 `http://192.168.4.1`。

## 11. 隐私与安全

- 设备只与局域网内的 Roon Core 通信，不连接任何云服务。
- Wi-Fi 密码只保存在设备本机。
- 配网用的 CoverArt-XXXXXX 网络没有密码，只在配网模式下开启，连接成功后即关闭。
